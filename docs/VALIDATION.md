# 1.0 점검 기록

## 고친 문제

| 확인한 부분 | 1.0의 동작 |
| --- | --- |
| 실리태번 모바일에서 패널이 2px로 접히고 손잡이가 화면 맨 위에 붙음 | 높이·위치를 `dvh`로 지정. 실리태번 1.19.0 모바일 화면(Pixel 7 에뮬레이션)에서 패널 높이 771px, 손잡이가 화면 40% 위치에 오는 것 확인 |
| QR이 띄운 실리태번 선택창에서 Esc를 누르면 패널까지 닫힘 | 실리태번 팝업이 열려 있으면 패널을 그대로 둠 |
| 휴대폰에서 QR을 눌러도 패널이 응답을 가림 | 「QR을 누른 뒤 패널」 옵션 추가, 기본은 좁은 화면에서만 닫기 |

## 추가한 것

- 확장 이름을 「커스텀 스튜디오」로 변경
  - 이전 이름의 설정을 자동으로 옮겨 옴
  - 이전 테마 형식도 계속 읽음
- 내장 테마: 스카이 블루 · 민트 그린 · 시크 모던 (`themes/index.json`)
- 지금 화면에 미리보기: 저장 없이 입혀 보고, 닫으면 원래대로 복구

## 확인한 범위

- **Node 단위 테스트 21개**
  - 내장 테마의 형식 검사와 왕복 저장
  - 글자 대비: 본문 7:1, 보조·강조 4.5:1 이상
  - 이전 형식 호환
- **실리태번 1.19.0 로컬 서버**
  - 기능 확인
    - 패널에서 QR 실행 → 생성 → 응답 표시
    - 테마 전환과 내장 테마 목록
    - 미리보기 적용과 해제(저장된 테마는 바뀌지 않음)
    - 영역별 CSS의 `@keyframes` 동작
    - 휴대폰 크기에서 QR을 누른 뒤 패널이 닫힘
  - 응답 생성은 시험용 가짜 서버로 대신했습니다.
- **사용자 CSS에 지지 않는 테마 적용**
  - 재현 환경
    - 실리태번 1.19.0
    - 밝은 SmartTheme 변수
    - `!important`로 상단 바 · 메시지 카드 · 대사 상자 · 입력창 · 서랍 · 배경을 고정한 사용자 CSS
  - 수정 전: 상단 바와 메시지 카드 안쪽이 사용자 CSS 색으로 남음(제보 화면과 같음)
  - 수정 후: 다음 테마 모두에서 배경 · 상단 바 · 메시지 · 대사 · 지문 · 입력창 · 서랍이 테마 색으로 바뀜
    - 테마: 모던 큐티 · 스카이 블루 · 민트 그린 · 시크 모던 · 렐릭타 솜니움
    - 채팅 모드: 평면 · 말풍선
    - 화면: 데스크톱 · 휴대폰
  - 봇 정규식이 만든 HTML 카드(렐릭타 길드 채팅 등)의 인라인 색은 그대로 유지됨
- **구버전 실리태번 호환**
  - 확인한 버전: 1.11.8 · 1.12.14 · 1.13.5 · 1.15.0 · 1.17.0 · 1.19.0
  - 버전마다 같은 데이터로 확인한 항목
    - 확장 로드
    - 캐릭터 진입 시 테마·영역별 CSS 적용
    - 기본 QR 바 숨김
    - 패널의 세 세트 17개 버튼 표시
    - 패널에서 QR 실행
    - 설정창 열기
    - 1.11.8 · 1.13.5 · 1.17.0은 휴대폰 화면(Pixel 7)도 확인
  - 1.10.10: 테마는 적용되지만 QR API가 없어 패널이 비어 있음
    - 이 때문에 manifest의 최소 버전을 1.11.0으로 둡니다.
    - 1.12 이하는 최소 버전 검사를 하지 않습니다.
- **독립 미리보기(preview.html)**: 내장 테마 표시, 오류 없음

## 수동 재현 방법

1. 캐릭터 A의 1:1 대화방에 시크 모던을 지정하고 HTML/CSS 적용을 켭니다. A의 다른 대화방으로 이동해도 디자인이 유지되는지 확인합니다.
2. 테마가 없는 캐릭터 B나 그룹 대화로 이동해, 상단 메뉴·메시지·입력창·패널이 각 대화의 설정으로 돌아오는지 확인합니다.
3. 휴대폰에서 패널을 열고 QR 하나를 누릅니다. 패널이 닫히고 응답이 보이는지 확인합니다.
4. 테마 만들기에서 색을 바꾸고 「지금 화면에 미리보기」를 누릅니다. 「미리보기 끝」을 누르면 원래 테마로 돌아오는지 확인합니다.
5. `Alt+Shift+Q` 또는 주소의 `cqs-safe=1`로 소스를 잠시 끕니다. 설정을 다시 열어 CSS를 고치거나 테마를 바꿀 수 있는지 확인합니다.

단위 테스트 명령은 `node --test tests/*.test.mjs`입니다.
