# 커스텀 스튜디오 (Custom Studio) 1.0

SillyTavern 캐릭터별 테마와 Quick Reply 사이드패널입니다. 캐릭터마다 채팅, 상단 메뉴, QR 패널을 따로 켤 수 있습니다. 기본 테마는 밀키 핑크와 라벤더를 조합한 **모던 큐티**입니다. 이 밖에 **스카이 블루**, **민트 그린**, **시크 모던**이 내장되어 있습니다.

## 1.0에서 바뀐 것

- **이름 변경:** 확장 이름이 「커스텀 스튜디오」로 바뀌었습니다.
  - 이전 이름으로 저장한 캐릭터 설정과 테마는 처음 켤 때 자동으로 옮겨 옵니다.
  - 이전 형식의 테마 파일도 그대로 가져올 수 있습니다.
- **화면 전체 테마:** 테마 색이 화면 배경 · 채팅 칸 · 메시지 칸 · 입력창 · 기본 QR 막대 · 상단 메뉴 · 서랍까지 모두 바꿉니다.
  - 실리태번 테마의 사용자 CSS나 다른 꾸미기 확장이 `!important`로 색을 고정해 두어도 캐릭터 테마가 우선합니다.
  - 테마의 채팅 CSS · 상단 메뉴 CSS도 같은 방식으로 최우선 적용됩니다.
  - 캐릭터 설정의 「채팅 화면 꾸미기」 · 「상단 메뉴·서랍 꾸미기」로 영역별로 끌 수 있습니다.
- **내장 테마 디자인:** 네 가지 내장 테마에 배경 · 상단 메뉴 · 메시지 칸 · 입력창 디자인이 들어 있습니다. 확장과 함께 배포된 소스라서 처음부터 켜져 있습니다.
- **확장 목록 버튼:** 확장 목록의 「커스텀 스튜디오 · 캐릭터 테마 설정」 버튼이 한 글자씩 세로로 쌓이던 문제를 고쳤습니다.
- **휴대폰 패널 수정:** 휴대폰에서 QR 패널이 접혀 보이지 않던 문제를 고쳤습니다.
  - 원인은 실리태번 모바일 구조였습니다. `body`가 `position:fixed`이고 `html`에 `transform`이 걸려 있어서, 고정 요소의 기준 높이가 0이 되었습니다.
  - 이제 패널 높이와 손잡이 위치를 화면 단위로 지정합니다.
- **내장 테마:** 스카이 블루 · 민트 그린 · 시크 모던을 가져오기 없이 바로 고를 수 있습니다.
  - 목록에는 「· 내장」으로 표시됩니다.
  - 고쳐 쓰려면 id를 바꿔 새 테마로 저장하세요.
- **지금 화면에 미리보기:** 편집 중인 테마를 저장하지 않고 현재 캐릭터에 잠시 입혀 봅니다.
  - 설정창은 아래 막대로 접히고, 패널 버튼도 눌러 볼 수 있습니다.
  - 「미리보기 끝」을 누르거나 설정창을 닫으면 원래대로 돌아갑니다.
- **QR을 누른 뒤 패널:** 「좁은 화면에서만 닫기(기본) · 항상 닫기 · 열어 두기」 중에서 고릅니다.
- **Esc 동작:** QR이 띄운 실리태번 선택창이 열려 있을 때 Esc를 눌러도 패널은 닫히지 않습니다.

## 설치와 업데이트

1. ZIP에서 `custom-studio` 폴더를 꺼냅니다.
2. **실리태번 서버가 있는 기기**의 `SillyTavern/data/<사용자 핸들>/extensions/`에 폴더를 복사합니다. 기본 사용자 핸들은 보통 `default-user`입니다.
3. `.../extensions/custom-studio/manifest.json`이 바로 보이면 설치 경로가 맞습니다. 기존 버전은 같은 폴더에 덮어씁니다. 기존 사용자 설정과 테마는 유지됩니다.
4. 실리태번을 새로고침하고 확장 관리에서 **커스텀 스튜디오**와 기본 **Quick Replies**를 켭니다.

모든 사용자에게 설치할 때는 `SillyTavern/public/scripts/extensions/third-party/`에 같은 폴더를 넣을 수 있습니다. 두 위치 중 하나를 사용하세요. Termux에서 실행 중이라면 Termux의 실리태번 폴더에 설치합니다. ‘확장 설치’ URL 입력칸은 Git 저장소용입니다.

대상은 **SillyTavern 1.11.0 이상**입니다(1.11.8 · 1.12.14 · 1.13.5 · 1.15.0 · 1.17.0 · 1.19.0에서 확인). 1.10 이하에서는 테마만 적용되고 QR 패널은 비어 있습니다. HTML 구조 편집은 브라우저 내장 기능을 사용하며 영역별 CSS에는 `@scope`를 지원하는 브라우저가 필요합니다. [SillyTavern UI 확장 문서](https://docs.sillytavern.app/for-contributors/writing-extensions/)

## 캐릭터에 테마 지정

1. 캐릭터의 **1:1 대화방**을 엽니다.
2. **확장 설정 → ✦ 커스텀 스튜디오 · 캐릭터 테마 설정**으로 들어갑니다.
3. **이 캐릭터에 테마 사용**을 켜고 테마를 선택합니다.
4. QR 사이드패널, 채팅 꾸미기, 상단 메뉴 CSS 중 사용할 항목을 선택합니다. 패널을 쓸 경우 연결할 QR 세트와 패널 위치도 지정합니다.
5. **캐릭터에 적용**을 누릅니다.

‘실리태번 채팅 형식 유지’는 기본형·말풍선형·문서형의 배치와 표시 규칙을 따릅니다. 기존 프로필의 ‘카드 모양 (메시지마다 상자)’도 선택할 수 있습니다. 같은 캐릭터의 기존·신규 대화방에 설정이 적용되고, 다른 캐릭터나 그룹 대화로 이동하면 그 대화에 해당하는 디자인이 표시됩니다.

## 패널, 채팅, 상단 메뉴를 소스로 편집

1. **테마 만들기 · 가져오기 / 내보내기**를 펼칩니다. 기본 테마를 복제할 때는 새 id와 이름을 입력합니다.
2. **소스 편집 · 패널 HTML과 영역별 CSS**를 열고 원하는 칸에 코드를 입력합니다. 처음이라면 빈 칸 아래의 **예제 넣기**를 누릅니다.
3. **테마 저장**을 누르고, 캐릭터 설정에서 **이 캐릭터에서 테마의 HTML/CSS 적용**을 켠 뒤 **캐릭터에 적용**을 누릅니다.

| 편집칸 | 바꿀 수 있는 범위 |
| --- | --- |
| 패널 HTML | 헤더, 장식, 버튼 목록, 검색, 닫기, 새로고침, 상태줄의 배치 |
| 손잡이 HTML | 아이콘과 문구 배치, 장식 마크업 |
| 패널 · 손잡이 CSS | 위치, 크기, 레이아웃, 배경, 테두리, 상호작용 상태 |
| 채팅 · 배경 · 입력창 CSS | 메시지, 본문, 아바타, 배경, 입력창, 전송 및 채팅 옵션 버튼 |
| 상단 메뉴 CSS | 실리태번 상단 바, 아이콘, 펼쳐지는 메뉴 영역 |

소스가 있는 테마를 가져온 경우 내용을 확인한 뒤 켜세요. CSS나 HTML이 외부 이미지를 참조하면 브라우저가 해당 주소로 요청할 수 있습니다. JavaScript, 이벤트 속성, iframe과 인라인 SVG는 소스 편집 범위에서 제외됩니다.

소스로 화면을 조작하기 어려워졌다면 **Alt+Shift+Q**를 누르거나 접속 주소에 `?cqs-safe=1`을 붙여 다시 엽니다. 이미 쿼리 문자열이 있으면 `&cqs-safe=1`을 붙이세요. 해당 페이지에서 HTML/CSS를 끈 채로 캐릭터 설정을 다시 열 수 있습니다.

## QR 버튼별 배경, 아이콘, 모양

1. 기본 **Quick Replies**에서 QR 세트를 먼저 등록합니다.
2. **테마 만들기 → 테마별 QR 아이콘**에서 세트와 **개별 QR**을 고릅니다.
3. 아이콘을 지정하고 **선택 아이콘 반영**을 누릅니다. 아래 **개별 QR 버튼 디자인**에서 배경색, 배경 이미지, 모양을 고른 뒤 **QR 디자인 반영**을 누릅니다. 필요하면 개별 QR HTML/CSS도 입력합니다.
4. **테마 저장 → 캐릭터에 적용**을 누릅니다. 개별 QR HTML/CSS를 쓰려면 캐릭터의 소스 적용을 켭니다.

아이콘은 문자·이모지, Font Awesome, 업로드 이미지, 원본 아이콘, 숨김 중 선택할 수 있습니다. 버튼 모양은 각진 사각형, 둥근 사각형, 캡슐, 원형, 테마 기본값을 지원합니다. 개별 지정은 QR의 원본 ID를 우선 사용하므로 버튼 이름을 바꿔도 유지됩니다. 세트 이름을 바꾸거나 QR을 삭제 후 다시 만들면 연결을 다시 설정해야 할 수 있습니다.

원본 QR 동작을 사용하므로 메시지, 입력 칸 삽입, STscript, 원본 세트의 전송 옵션이 적용됩니다. 패널 연결은 기본 Quick Replies의 세트 활성화나 자동 실행 설정을 바꾸지 않습니다. QR을 수정한 뒤 패널의 **↻**를 눌러 목록을 새로고침할 수 있습니다.

## 배경과 테마 공유

- 채팅 배경은 **테마 만들기 → 채팅 배경 이미지**에서 올립니다. PNG/JPG/GIF/WebP, 최대 2 MB입니다. 이미지 크기·위치·반복, 덮개와 카드 투명도를 지정할 수 있습니다.
- 손잡이·QR 아이콘·QR 배경 이미지의 개별 제한은 256 KB입니다. 업로드 이미지는 테마 JSON과 함께 저장되고, 테마 하나의 전체 제한은 6 MB입니다.
- 테마를 공유하려면 **JSON 내보내기**를 누릅니다. 가져올 때는 **JSON 가져오기 → 테마 저장 → 캐릭터에 적용** 순서입니다. QR 세트 JSON은 실리태번 기본 Quick Replies에서 가져옵니다.
- 0.2.x · 0.3.x 테마를 그대로 가져올 수 있습니다. 테마 id를 덮어쓰면 같은 테마를 참조하는 캐릭터에 변경이 반영됩니다.
- 캐릭터의 아바타 파일명을 기준으로 연결합니다. 캐릭터 복제나 재가져오기로 파일명이 달라지면 다시 지정하세요.

## 포함된 문서와 미리보기

- `THEME_GUIDE.md`: 사람용 테마 제작 가이드. 색·이미지 → 버튼별 꾸미기 → 소스 편집 순서로, 슬롯·CSS 적용 범위·JSON 항목·제한을 정리했습니다.
- `THEME_GUIDE_AI.md`: AI에게 테마를 맡길 때 그대로 붙여 넣는 사양서. 스키마·허용 태그·함정·검증 체크리스트·예제가 들어 있습니다.
- `themes/`에 내장 테마 목록(`index.json`)과 기본 테마들이 있습니다. `chic-modern.json`은 패널 HTML과 영역별 CSS를 쓰는 예제이기도 합니다. `modern-cutie.json`은 0.2.x 형식 예제입니다.
- `preview.html`은 브라우저에서 열어보는 독립 미리보기입니다. 샘플 QR은 미리보기 결과만 표시합니다.
- `docs/VALIDATION.md`에 점검 결과와 검증 범위를 기록했습니다.
